# 无线电：初步问题自动来电（试验分支 feature/radio-intro-popups）

目的：让"建立图形对应 / 对图形的最初步判断 / 照相重复 / 探照灯发现"这类入门问题不再由玩家自己挑证据去问，减轻无线电里一次堆太多内容的问题。

## 行为

1. 条件满足时，无线电自动弹出，已选好问题、已填好证据，玩家只需点 **Send evidence**。
   条件：该问题当前可问（对比关系、照相图案或探照灯发现已经成立）、预填证据已拥有、该碑已记录、玩家在该碑所在的城市、新手教程已结束。
   满足后停 0.9 秒再弹（让"已记录"的提示先出现）；正在拖拽拓印、对话、拍照时不弹。
2. 一次只弹一条。同时有几条等着时，其余的不会自己弹；回答完这条挂断后，再打开无线电，下一条会已经填好。新出现的对应关系会在通话结束后自己弹。
3. 玩家挂断（End call / Esc）不会再自动弹；下次手动打开无线电时，这条仍然已经填好，等着发送。
4. 问题得到真正回答后（不是"换一份证据试试"的提示），写入 `radio_progress["intro_done"]`，**不再出现在无线电问题列表**，对话保留在 Radio Logs。
5. 旧存档（没有功能标记的存档）第一次进入时：已经用对证据听过的记为已完成；其余当时就已满足条件的记入 `intro_skipped`，保留为普通问题，不自动弹、也不预填，避免一次弹出一大堆。全新游戏不受影响。
6. 用错误证据手动问，只得到提示的话，问题不会被用掉。

## 修改名单

`assets/dialogue/radio_intro_calls.json`：`question` 是 radio_content.json 里的问题 id，`evidence` 是要预填的证据 id（空字符串 = 不带证据直接问）。删掉一行就让该问题恢复旧的手动方式。

当前 19 条：
- 图形比对：水晶碑、双身兽（学者碑、太阳碑）、婴儿对应（祭坛）、水晶神形状、干河、手牵手皮肤画、天梯路径
- 照相重复：重复的兽、共用底座、祝福符号、孩子形象（圣母碑、圣父碑）
- 夜城符号初读：干河边框、上升纹、水晶神
- 探照灯发现：圣母碑上的花、祭坛的月形石、被取走的水晶神

不含：婴儿碑（教程）、孤独碑（终局调查）、需要玩家推理的隐藏问题和多层追问。

## 已知取舍

- 一个问题一旦标为已完成就整个隐藏，其后需要别的证据才能听到的追问层不再能从列表进入。名单里这 19 条目前都只有"有支撑 / 提示"两种回答，没有后续层；以后新增条目前请先确认。
- 圣母碑和圣父碑上相同的问题（如祝福符号、水晶神形状）在不同碑下是不同的问题 id，只有名单里写到的那一个会自动来电。

验证：`tools/radio_intro_test.gd`（弹出、预填、回答后隐藏、日志保留、连续来电、挂断不重弹、提示不耗尽问题）。
