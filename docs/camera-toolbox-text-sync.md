# 相机、工具箱与文案同步

## 相机教学
婴儿报告结束对白后，发放昼城文献，随后播放相机旁白、快门声与闪光，显示当前墓园照片。黑色边框内使用轻微动态颗粒；教学照片上的三个共用基座部位闪蓝光，点击3处才生成 shared_family_base，照片本身不生成证据。

教学结束进入正式调查状态。再打开相机后没有自动蓝光，玩家自己点选重复细节；相机只在完整匹配已配置组合后分析，不会因乱点或重复点击同一位置而直接给结论。观察选择保存在 camera_observations，可跨照片/昼夜积累。

当前组合：三墓共用基座 → shared_family_base；昼城三处双头兽 → repeated_beast_motifs；昼城弧形与夜城月亮 → moon_reference（只说明形状相似，不直接断言文化或死因）。

照片场景用已有学者、婴儿、大亨透明素材排出三个墓碑和连续基座；新增兽纹及基座为可替换布局占位。camera_shutter.wav 是本地生成的占位快门音效，后续可替换。相机仅用于重复观察，皮肤画仍由探照灯揭示。

## 工具箱
拓印、探照灯、相机合在 Toolbox。悬停或点击工具箱按钮，左边展开纵向工具列。选择工具后收起；新手提示需要某个工具时自动展开并高亮对应按钮。

笔记本和无线电保留单独入口。工具箱按钮是原工具按钮的代理，不移动原节点，保留已有程序路径和信号。
