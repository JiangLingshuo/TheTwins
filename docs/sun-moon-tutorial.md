# 日月切换教程试作

分支：feature/sun-moon-tutorial。此前笔记本、手稿列表、探照灯和开场更新已经单独推入 main，本分支仅叠加本次教程试验。

## 流程

0. 先放大：拓印只对镜头推近的那块碑有效（RubbingTool.can_rub）。没推近婴儿碑时，提示停在“点放大镜”，婴儿碑的放大镜常驻并高亮；推近后才进入工具箱/拓印步骤，中途拉回全景会退回这一步。月牙落进笔记本前镜头自动拉回全景，方便下一步拖到天上。放大镜任何时候都可用，不受教程门槛限制。
1. 左上提示拿起拓印工具，高亮工具按钮。
2. 直接指向婴儿碑基底的小月牙，无需拓印天空太阳。
3. 拓印婴儿碑基底的小月牙，高亮对应区域。普通人形拓印暂缓至教程完成后。
4. 播放三句发现对话：Aurora — There seems to be a crescent shape on the base. 玩家 — Kinda similar to the shape of the moon on Earth. Aurora — Try it. 复用通用 DialogueBox，不接管学姐正在开发的正式无线电界面。实际播放后进入 Radio Logs，且同一流程只播放一次。
5. 拓印完成后碑上的月牙闪烁（对话期间持续，至少 moon_blink_time 秒），然后月牙从碑上升起悬停，笔记本以两倍速打开到 Rise & Set；书完全翻开后月牙才落到黑页并放大到图标大小（落下前两页都不显示日月，此时只有月亮入册）。之后月亮图标持续闪烁，直接进入 4/4 拖动提示。月亮第一次替换太阳进入夜城时，天上的太阳以同样的动画落进白页（太阳此时才入册），然后笔记本合上，再播 Aurora 的夜城台词。日月都入册后，除 Rise & Set 外每一页左上角（白页）有小太阳、右上角（黑页）有小月亮，可直接拖到天上切换昼夜。玩家关掉笔记本时仍回到“打开笔记本 / 选 Rise & Set”的提示。名字取升起与落下的含义，避免 wax and wane 只指月相；可继续改名。
6. 专用跨页：左白页一个太阳，右黑页一个月亮。月亮来自小碑拓印；太阳为教学自动提供，两个图标均可复用。
7. 拖右页月亮出书本，书本收起；放到场景太阳上进入夜城，教程完成。放错可重试，图标不会消耗。
8. 完成后图标可复用：太阳拖到夜城月亮上返回昼城，月亮拖到昼城太阳上进入夜城。

左上保持短步骤提示并高亮当前目标。开发构建有 DEV — skip tutorial，直接跳到夜城并补齐导航图标；测试完整流程请勿使用 F8 全内容预览。现有 F1 仍是开发调试切城键，非正式教程解法。

## 状态与边界

- 使用现有拓印工具；新增 sky_sun_rubbing 导航图标。它不是太阳形职业碑，不解锁大亨身份。
- 两个导航图标不重复出现在普通 Rubbings 页。婴儿碑上的月亮拓印仍归该碑，点击其拓印槽会前往专页。
- 日月替换不调用 confirm_rubbing_meaning，不把导航操作误记为“月亮表示自然死亡”。正式符号解读仍可由后续问答完成。
- Rise & Set 是第六个页签（index 5），昼夜纸色在该跨页启用；六个标签自动收紧间距，避免最下方标签超出封面。
- cycle_hint_heard 与 cycle_tutorial_completed 保留在 GameState，避免重建主场景时重复播放。当前没有新增磁盘存档。
- 本次没有新增其他墓碑关卡、正式无线电提交UI，也没有修改六身份规则。

## 验证

运行 tools/sun_moon_tutorial_test.gd：从真实拓印操作测试顺序门槛、Aurora、页签、双向拖放、错误重试与符号含义分离。加 -- --shots 可保存实际流程截图到忽略目录 test_output/sun_moon_tutorial。
