# 探照灯文字占位清单

教程分支内所有现有 tool:searchlight 线索均已放入场景：11项，昼城7项、夜城4项。文字卡常驻显示名称和测试年份，方便团队定位；收录仍需要选中卡片范围、调对年份并稳定照射0.7秒。位置是待美术替换的布局占位，不代表最终墓碑位置。

两项空扫描先后检查45和0年两个端点，顺序不限；重复照一个端点不重复计数，检查两端才收录。这里是范围检查的原型简化，不把空白当作某一年的实体物件，也不将其作为拓印拖拽对象。

正向历史物件获取后保留为场景比对目标，关灯或开本子仍可拖拽。正文仍写入原有证据ID，文献获取途径不变，不移动现有Manuscripts。

刻度0—250年，普通滚轮1年，Shift+滚轮10年。250年只是现有古代日期占位，未新定世界观年表。

## 编辑入口
- 位置、名称、对应目标、终局门槛：assets/dialogue/searchlight_placeholders.json。
- 年份以 evidence_master.ink 元数据导出的 notebook_content.json 为准，main.gd读取元数据优先于布局文件中的日期副本；修改源文本后运行 tools/build_notebook_content.py。
- 文字占位与获取行为：scripts/historical_target.gd。
- 验证：tools/searchlight_placeholders_test.gd。
