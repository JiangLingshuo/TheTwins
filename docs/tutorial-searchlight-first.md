# 当前新手顺序：手稿 → 探照灯 → 无线电

本说明覆盖旧教学文档中“先无线电再探照灯”的安排。

1. 日月切换回昼城，拓印人形并自动登记小碑，打开笔记本展示记录。
2. 阅读两份设计者文献，点击关键词，并返回列表或合上笔记本。
3. 播放 tutorial_searchlight_intro.xml：主角介绍探照灯，读出“Rewind time to see the traces of the past”。
4. 引导关闭笔记本、点击探照灯、点击小碑人形或基座锁住光圈。滚轮调整至50年前（2000），Shift+滚轮可10年一档。位置固定，稳定照射后收录 infant_graffiti。
5. 播放 tutorial_searchlight_found.xml，说明发现的涂鸦不同于纪念形象，并已记录在 Clues。
6. 再播放 tutorial_radio_ready.xml，进入证据、隐藏问题、隐藏回答教学。真实相貌与死因疑点使用探照灯涂鸦，不使用设计者日记替代。
7. 填写调查表，播放结束台词，发昼城文献。

Clues 现在是所有已收集非手稿、非拓印线索的总索引；墓碑相关线索仍同时在对应墓碑页展示，使用同一证据ID，不新建重复证据。之前“墓碑线索不进入Clues”是列表为空的原因，现已调整。

照射位置：除原文字占位卡以外，小碑人形/基座的 Rect2(760,480,220,300) 原画坐标也能发现涂鸦，避免必须精确照在占位文字上。其他线索保持原有位置与年份。

验证：tutorial_manuscript_flow_test.gd 从手稿阶段开始，通过实际滚轮处理把40年调到50年，确认错误年份不能开放无线电，正确发现后Clues和墓碑页均可见。
